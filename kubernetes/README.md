# RepoX Kubernetes Configuration

This directory contains Kubernetes configuration files for deploying the RepoX application.

## Directory Structure

- **`/core`** - Essential files for basic deployment
  - Deployments, services, ingress, and secrets
  - Start here for basic deployment

- **`/monitoring`** - Advanced monitoring setup
  - Prometheus and Grafana configurations
  - For advanced users

## Getting Started

For beginners, follow these steps:

1. Start with the files in the `/core` directory
2. Follow the instructions in the main DEPLOYMENT.md file
3. Only move to the `/monitoring` directory after mastering the basics
